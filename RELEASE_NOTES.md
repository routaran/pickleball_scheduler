# DUPR Mobile App - Release Notes

## Version 1.0.0 (Initial Release)

### Features
- **DUPR Ladder**: Process player lists and generate sorted pool assignments
- **Partner DUPR**: Calculate team ratings using 35%/65% formula
- **PickleBros Monday**: Fixed 4-player pool distribution
- **Player Lookup**: 8-tier cascade search with fuzzy matching
- **HTML Reports**: Generate professional HTML reports with rating tiers
- **Export Options**: Copy, Share, Print, and PDF export
- **Player Overrides**: Manual rating overrides for specific players
- **Secure Authentication**: WebView-based DUPR login with secure token storage

### Technical Highlights
- Built with React Native / Expo
- TypeScript throughout
- 99%+ test coverage on core logic
- Offline-capable player registry

### Known Limitations
- Requires DUPR account for authentication
- Android only (iOS coming in future release)
